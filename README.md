# Weather App - Task 05 | SkillCraft Technology Internship

A responsive web app that fetches real-time weather data using OpenWeatherMap API.

### ✨ Features
- 🔍 Search weather by city name
- 📍 Get current location weather using Geolocation API
- 🌡️ Shows temperature, humidity, wind speed, weather condition
- 📱 Fully responsive for mobile & desktop

### 🛠️ Tech Stack
HTML5, CSS3, JavaScript, OpenWeatherMap API

### 🚀 How to Run Locally
1. Get free API key from openweathermap.org/api
2. Replace `API_KEY` in script.js with your key
3. Open `index.html` in browser
